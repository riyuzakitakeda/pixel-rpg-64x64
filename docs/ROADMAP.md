# Development Roadmap

## Phase 1 — Project foundation
- [ ] Select engine and supported platforms
- [ ] Define resolution, camera, tile grid, and 64×64 sprite rules
- [ ] Create a playable test scene
- [ ] Add input, movement, collision, and camera follow

## Phase 2 — First playable slice
- [ ] Build one small outdoor map
- [ ] Add player idle and walk animations
- [ ] Add one NPC with dialogue
- [ ] Add one enemy and a basic encounter
- [ ] Add a simple inventory and item pickup
- [ ] Add one short quest with a reward

## Phase 3 — Core RPG systems
- [ ] Implement stats, experience, and leveling
- [ ] Implement equipment and consumables
- [ ] Implement save/load
- [ ] Add menus, HUD, audio, and settings
- [ ] Add additional enemy behaviors and encounters

## Phase 4 — Content production
- [ ] Expand maps, interiors, and dungeons
- [ ] Produce NPCs, enemies, items, and tilesets
- [ ] Add quests, dialogue, and story events
- [ ] Balance progression and difficulty

## Phase 5 — Polish and release
- [ ] Optimize performance and memory use
- [ ] Test on target devices
- [ ] Fix gameplay, UI, and accessibility issues
- [ ] Prepare release builds and store materials

## Milestone rule
Keep each milestone playable. Do not expand content before the movement, interaction, combat, and save foundations are stable.
